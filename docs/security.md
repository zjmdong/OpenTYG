## 凭据生命周期

<a id="凭据生命周期--credential-lifecycle"></a>

| 状态 | 有效期与行为 |
| --- | --- |
| 未勾选记住登录 | 浏览器会话最多 12 小时，服务重启后不恢复 |
| 勾选记住登录 | 最长 30 天绝对期限，加密保存恢复状态；平台可能提前使其失效 |
| 退出登录 | 撤销该账号在本服务的所有浏览器会话，删除保存的登录凭据，保留收藏与设置 |
| 平台主凭据过期 | 清理该账号的内存登录、保存凭据与本服务会话，提示重新登录；其他账号不受影响 |
| 房产临时凭据过期 | 在原连接准备时限内刷新一次；失败即返回错误，不重复发送开门指令 |

主凭据过期特指房产权查询明确返回平台 `1002` / `Token过期`。单个浏览器 Cookie 过期、普通网络故障或其他业务拒绝不会触发账号级清理。当前 SDK 没有主登录凭据续期接口，记住登录不保证 30 天始终免登录。

密码与短信码经同源请求交给后端，再按平台协议发送。应用不把密码写入日志、偏好或记住登录文件，未使用的对讲密码保留功能已关闭。

浏览器仅持有本服务签名的随机会话 Cookie，生产属性为 `HttpOnly`、`Secure`、`SameSite=Strict`；不接收上游登录 token、开门 authcode 或房产 token。已授权用户仍可查看自己的名称、脱敏账号和房产信息。

如果同账号另有记住登录的浏览器，其恢复凭据可继续保留。过期且不再被记住的凭据会定期清理；偏好不自动到期，管理员需自行制定保留与删除策略。

## 磁盘上保存什么

| 文件 | 内容与保护 |
| --- | --- |
| `secrets/opentyg_secret.txt` | 外部随机秘密；主机上的明文文件，须独立保护 |
| `data/.app-secret` | 随机数据密钥，由外部秘密封装 |
| `data/users/*.blob` | 被记住的登录恢复数据，AES-256-GCM 加密 |
| `data/prefs/*.prefs`、`*.prefs.bak` | 加密的用户/房产偏好，以及上一份写入前备份 |
| `data/sessions.json` | 加密的记住登录会话记录 |
| `data/auth-limits.json` | 加密的认证限流记录，不存密码 |

以上是默认路径；以实际 Compose 配置为准。用户文件名由外部秘密和账号通过 HMAC 派生，限流账号标识使用用途绑定的 HMAC。加密文件使用随机 IV、认证标签和用途绑定上下文。凭据、偏好、会话与业务限流共用随机数据密钥；外部秘密还用于标识派生和 Cookie 签名。

**加密主要保护泄露的数据目录副本。** 同时拿到密钥、主机管理员权限或进程控制权时，不再有这一保护。普通 Compose secrets 是文件挂载，不是主机密钥保险库；TLS 私钥由代理环境另行管理。

## 写入、备份与恢复

存储先同步临时文件，再原子替换目标；POSIX 环境还同步父目录，新私有文件权限为 `0600`。偏好覆盖前保留上一份加密备份。载入失败、缺少数据密钥或认证限流写入失败会报错，不静默生成新密钥或清空限流。

这些措施不能替代备份，也不保证故障磁盘或所有网络文件系统的持久性。使用可靠的本地文件系统，保持一个实例独占数据目录。

1. 停止服务，备份 Compose、完整数据目录（含隐藏文件）和原始外部密钥。
2. 保护备份的访问权限；自定义路径及使用中的 `.env` 也须备份。
3. 恢复时保持原密钥、文件所有者和权限，再启动单个实例。
4. 手动替换数据文件后重启服务，避免继续使用旧的内存偏好缓存。

不要把运行数据、密钥、证书私钥或原始日志提交到 Git。具体命令见 [部署指南](deployment.md)。

## 认证限流

| 操作 | 持久规则 |
| --- | --- |
| 发短信 | 同手机号跨浏览器共享：1 小时最多 3 次，12 小时最多 12 次 |
| 密码错误 | 10 分钟内第 4 次开始，锁定该账号的新登录 1 小时；密码和短信登录均受限 |

成功和结果不确定的短信发送计数；明确未发送的拒绝可退还次数。设备验证、网络失败不计为密码错误。限流重启后仍生效，但不注销已登录会话。

代理后的短窗口网络限流可能按代理来源共享；业务账号限流仍独立。大规模攻击和入口保护需按部署规模另行设计，本应用不是通用身份认证平台。

## 网络与上线检查

生产使用固定 HTTPS `PUBLIC_ORIGIN`、Secure Cookie、精确 Host / Origin 和请求标记校验。内部 HTTP 端口只向回环或受控内网开放，代理/CDN 不缓存私有响应。

默认 HTTP / WS 上游兼容会使后端到平台的通信保持明文，可能暴露登录与门禁凭据。浏览器 HTTPS 和主机名单都不能加密这一段；只有验证上游支持 HTTPS / WSS 后，才能关闭 HTTP 兼容。

上线时核对域名与证书、代理端口和 Origin、内部端口隔离、文件权限、密钥备份、单实例和实际账号权限。避免记录请求体与凭据；日志默认写到标准输出并由 Docker 轮转，分享前仍需检查。项目未包含外部分析服务；自行添加的监控、CDN、备份和日志服务需单独评估数据去向。

## 内存与操作边界

登录/配置缓存最多约 24 小时闲置、200 个账号，可能提前 LRU 回收；WebSocket 闲置 30 分钟释放。会话过期立即拒绝访问，定期清理对应登录缓存；退出立即清理。较长内存驻留不延长会话有效期，也不保护被控制的主机。

房产权验证最长复用约 60 秒。久置、断线恢复或验证过期后重新查询权限。首页的旧收藏视图只供展示，不是授权；所有写入更新偏好缓存，多个写入进程不受支持。

**指令可能已发送时，没有回执不等于没有开门。** 协议没有供本实现使用的幂等请求编号，因此结果未知时必须由用户核实现场，不能自动重发或排队重放。

本项目不宣称经过正式安全认证或完整渗透测试。漏洞请按 [SECURITY.md](../SECURITY.md) 私下报告。
